# Support

## Bugs and feature requests

Use GitHub Issues for reproducible bugs and feature requests. Include only the minimum information needed to reproduce a problem.

Never post Wi-Fi SSIDs, Bluetooth names or MAC addresses, routine contents, order IDs, tokens, or personal data in an issue.

## Sensitive and purchase-specific support

Contact `support@danielkindl.dev` for sensitive or purchase-specific support. Do not post payment details, purchase tokens, Google order IDs, or account identity in public issues.

Luvoq does not promise a strict support SLA.
