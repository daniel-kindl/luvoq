# Privacy foundation

Luvoq is local-first and privacy-first. Core automation must continue without internet, analytics, billing connectivity, or an application backend.

Phase 0 has no account, backend, Firebase, crash SDK, TelemetryDeck SDK, or cloud backup of routine configuration. Analytics is behind an application-owned no-op boundary.

Analytics must never include routine names, device names or addresses, Wi-Fi SSIDs, precise location, notification content, user-entered strings, raw configuration, purchase tokens, order IDs, payment details, or account identity.
