# Roadmap

## Phase 0: foundation

Project structure, repository governance, typed domain boundaries, persistence schema, UI shell, and CI.

## Phase 1: feasibility spike

Validate charging, battery threshold, Bluetooth, time, and Wi-Fi trigger mechanisms. Validate media volume, brightness, app opening, DND, and notification actions. Test foreground, background, killed process, locked screen, battery saver, reboot where relevant, Pixel, and Samsung.

Do not promise a capability until representative physical-device validation supports its reliability classification.
